# AE Bucket Boundary Canon v182

Status: CANON / TWO-BOUNDARY ISOLATION / APPEND-ONLY

Canonical primitive:

    {{0011 :: pt + {{n}}^{{n}}^{{n}} :: i}}

Expanded:

    {{0011 :: pt + {{n}}^{{n}}^{{n}} ::
      {{i = inf + 1{{B{{u}}cket}}}}}}

Bindings:

    0011 = plank 0 referent
    pt = local point
    n^n^n = retained nested scale
    inf = fulcrum / balance
    u = private disposable / pocket universe
    i = inf + 1u

The word itself supplies two container boundaries:

    B{{  u  }}cket
    ^          ^
 ingress     egress

Boundary 1 / ingress B{{ creates one private u while preserving the external
v181 parent, 0011 referent and local point exactly. Raw private payload is not
an exportable runtime value.

Boundary 2 / egress }}cket disposes u and emits only a sealed i receipt. The
receipt carries a hash and byte count for provenance but exposes zero raw
payload bytes. A disposed universe cannot be reopened or egressed twice.
