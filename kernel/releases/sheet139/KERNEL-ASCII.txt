STATE LATTICE
-------------
GENESIS -> PENDING(seq, policyHash, requiredNodes, verifiedAcks)
PENDING + ack_i -> PENDING  [when some nodes missing]
PENDING + all acks -> VERIFIED(seq, signed receipt, head hash)
PENDING + conflicting signed ack -> QUARANTINE  [blocks admission]
VERIFIED + new policy -> PENDING(seq+1)
VERIFIED + authorization -> inherited SHEET 138 gate

HARD BOUNDARIES
---------------
* All-required policy barrier, not an atomic distributed fleet transaction.
* Nonresponse => HOLD; fork => QUARANTINE; expired policy => HOLD.
* Signing keys are generated only in disposable tests. Real remote hosts NOT deployed.
* Full-disk rollback protection requires independently retained trusted head pin.
* Local file-lock coordination does not replace distributed fencing/consensus.
* No production authorization, global fork impossibility, or original SHEET 103 parity claim.
