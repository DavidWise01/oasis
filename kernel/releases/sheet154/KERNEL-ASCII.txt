 22 F-REPLICAS  sign S154:PREPARE votes bound to intent digest

 37 F-REPLICAS  validate all S147 prepare votes and chained entries
 38 F-REPLICAS  require 2+ independent signed COMPLETE journals
 39 F-REPLICAS  verify ANCHORED certificate / current anchor again
 40 F-REPLICAS  fsync FINAL and issue S154:FINAL signatures
 41 ROOT0        retain finality quorum receipt / signed high-water
 42 ROOT0        permit next authorized transaction / cutover

FAILURE / ADVERSARY BRANCHES
----------------------------
 ! Forged grant / receipt / physical leaf  => PREPARE denied
 ! 1/3 quorum / unavailable signer         => FAIL CLOSED
 ! Direct coordinator -> inner signer      => TLS reject
 ! Signed but stale anchor                 => REJECT
 ! Conflicting prepared transaction        => REJECT
 ! Gateway dies after inner fsync           => replay exact intent;
                                               no duplicate physical append
 ! Finality replica dies while ANCHORED    => process restart, durable replay
 ! One forged S147 completion journal      => insufficient finality quorum
 ! Damaged replica slot                    => hash-chain/slot check rejects
 ! Two of three finality nodes offline     => no progress
 ! Local SHEET142 timing-sensitive assert  => unresolved inherited issue

EXPLICIT BOUNDARIES
-------------------
 * Test architecture: distinct mTLS processes and state directories on one host.
 * Signed S147 grant and completion journals in the NEW gate are test fixtures;
   they are not fetched from running SHEET153 authority services by this gate.
 * Existing SHEET153 suite exercises live mTLS resource/authority/anchor tests.
 * One immutable finality slot; automated epoch rotation/compaction absent.
 * Signed anchor + signed quorum are crash-recoverable but not one atomic
   distributed commit over independently operated machines.
 * All participants use common local clock/host filesystem in this demonstration.
 * Not a production failover, power-loss durability or Byzantine consensus proof.
