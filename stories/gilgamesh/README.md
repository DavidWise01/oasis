# MOBIUS 0001 — Gilgamesh

Snapshot: 2026-09-19

Gilgamesh is the first MOBIUS story instance.

The useful benchmark is that its tradition is layered, copied, transformed, and still impactful long after every original participant is gone.

## Grounding

Surviving Gilgamesh literature is preserved in cuneiform clay-tablet traditions. Earlier Sumerian poems contributed material to later Akkadian forms, and the Standard Babylonian recension is traditionally associated with Sin-leqi-unninni.

## Author / picture rule

There is no authenticated life portrait of Sin-leqi-unninni. MOBIUS therefore must not invent one and present it as historical.

Use artifact, tablet, scribal-material, excavation-context, museum-object, or clearly labeled later interpretation instead.
