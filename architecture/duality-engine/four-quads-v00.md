# Duality Engine — Four Quads v00

Canonical outer glyph:

```text
((2x2))^((2x2))^2
```

In this layer the glyph denotes a **four-quad envelope**. It is not expanded as ordinary exponent arithmetic.

```text
[[ {
  4 quads ::::

  Q1 {
    a

  }

  ::::

  }

  ::::

  Q3 {
    1^1

  }

  ::::

  }

} ]]
```

## Exact numeric checks

The ordinary arithmetic subexpressions are:

```text
2^3 = 8
2^2 = 4
1^1 = 1
```

The token:

```text
0^0^0 = 81
```

is preserved as an **OaSIs symbolic/root equality**. It is not asserted as standard exponent arithmetic.

## Q1 — ablation gate

Q1 is a 13-bit-width emergent gate:

```text
input
  ↓
a / ablation
  ↓
must pass width = 13
  ↓
8 or 2^3
  ↓
logic deescilation
```

No bit pattern is invented here; only the required width is encoded.

## Q2 — verify cubic

```text
2^2 = 4
verify cubic
```

The phrase `verify cubic` is retained literally. No additional geometric meaning is inferred yet.

## Q3 — isomorphic pair

```text
1^1 = 1
isomorphic x isomorphic
```

The pair is retained as a literal isomorphic product.

## Q4 — root token

```text
0^0^0 = 81
```

This is the terminal symbolic/root token for the four-quad descent.
