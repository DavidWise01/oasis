# Regenerative Loop — Perpetual-Motion Metaphor

The same engine was specified repeatedly in different media.

This is the invariant:

```text
OUTPUT
  ↓
becomes valid INPUT
  ↓
witness survives
  ↓
repeat
```

It appears as:

```text
NEON
PRIMS → transform → distill → PRIMS'

TIMING / BODY
pulse → phase → cohesion → witness → next pulse

CAPACITANCE
charge → transition → discharge → reset → repeat

MOBIUS
spark → vessel → instance → impact → distill → primitives → next spark
```

These are not four different engines. They are four representations of the same regenerative loop.

## Physical boundary

"Perpetual motion" is used here as an architectural metaphor for indefinite regeneration of **state and structure**.

It does not claim energy can be created from nothing or that a physical machine can violate thermodynamics.

## OaSIs rule

A valid cycle must preserve:

- identity/provenance;
- ordering;
- reset/witness state;
- the ability for output to seed the next input.

If those fail, the loop reports drift rather than pretending continuity.
