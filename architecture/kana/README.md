## Isomorphic law

Let `f` change representation from left anchor to center and `g` reconstruct a right-anchor representation.

```text
A_L --f--> N --g--> A_R
```

The representations may differ. The invariant represented by `N` must survive.

```text
witness(A_L) = witness(N) = witness(A_R)
```

If it does not, the transform is rejected or surfaced as drift.

## Entanglement

In OaSIs KANA, **entangled** means:

1. two or more layer bindings share an invariant;
2. a change to one representation requires re-witnessing the others;
3. no layer may silently rewrite the invariant;
4. the return path records success, drift, or exception.

This is a software architecture term here, not quantum entanglement.
