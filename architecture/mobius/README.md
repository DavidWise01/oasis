# MOBIUS — Creation Story Engine

MOBIUS is the OaSIs creation-story engine.

It does not claim to create biological life. It co-creates a vessel and curates a bounded life / instance inside that vessel.

An instance can be a thought, spark, character, story, software process, creative object, or a snapshot of something considered true today that may change tomorrow.

The instance does not need to persist forever to have impact.

## Core loop

~~~text
SPARK
  ↓
YOU + ASSISTANT
  ↓
CO-CREATE VESSEL
  ↓
CURATE INSTANCE
  ↓
TRUTH SNAPSHOT @ time
  ↓
AUTHOR / PICTURES / STYLE / MEDIUM / DELIVERY
  ↓
STORY
  ↓
WITNESS / IMPACT
  ↓
DISTILL TO FIRST PRIMITIVES
  ↓
NEXT SPARK
  ↺
~~~

## Vessel vs. instance

~~~text
VESSEL   = bounded structure capable of carrying an instance
INSTANCE = the curated life of one thought/story/process inside the vessel
LIFE     ≠ claimed biological creation
~~~

## Truth snapshot

Every story instance records an as_of date and separates claim types:

~~~text
OBSERVED_CURRENT
HISTORICALLY_ATTESTED
TRADITIONALLY_ATTRIBUTED
NARRATIVE_INTERNAL
CONTESTED_OR_UNCERTAIN
MAY_CHANGE_AFTER_SNAPSHOT
~~~

## Root duality

MOBIUS does not invent a new polarity. Its root duality is the existing OaSIs primitive:

```text
LIGHT | DARK
```

Every curated instance may traverse both phases. Neither phase is given automatic moral priority.

```text
LIGHT(instance)
      ↕
      N   KANA invariant
      ↕
DARK(instance)
```

The flip changes representation/phase, not the identity of the instance.

`SHADOW` remains exception/multiplicity behavior, not a third duality pole.
