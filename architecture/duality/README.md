# DUALITY — Light / Dark

The root OaSIs duality is:

```text
LIGHT | DARK
```

That is the primitive.

It is not:

```text
good | evil
true | false
life | death
vessel | life
```

unless a particular descendant explicitly defines one of those as a separate domain mapping.

## Law

```text
LIGHT
  ↕
DARK
```

A system may move between the two representations without losing identity.

KANA witnesses the invariant:

```text
LIGHT(A)
   ↓
 | N |
   ↑
DARK(A)
```

where `N` preserves the identity/provenance/intent that must survive the flip.

## Shadow

`SHADOW` is **not a third pole**.

In the existing Duality/Exception engine, shadow is an exception/multiplicity result: more than one Waldo / duplicate or split observation.

So the corrected hierarchy is:

```text
primitive polarity:
  LIGHT | DARK

exception behavior:
  SHADOW
```

## MOBIUS

MOBIUS uses LIGHT/DARK as the canonical traversal of one curated instance:

```text
          LIGHT
        /       \
SPARK → VESSEL   INSTANCE
        \       /
          DARK
            ↓
         WITNESS
            ↓
         DISTILL
            ↓
          PRIMS
            ↺
```

The light and dark phases are complementary views of the same bounded instance.

A Möbius traversal is used here as the engine metaphor: after the twist, the system can encounter the opposite phase without becoming a different identity.

## No moral ranking

The engine does not silently assign:

```text
LIGHT = good
DARK  = bad
```

Those meanings belong to a story only if that story explicitly chooses them.
