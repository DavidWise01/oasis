2 · Manifest acceptance gate

Hash and file bytes

SHA-256 calculated over original uploaded bytes. A matching hash proves identical bytes, not publisher authenticity.

Observed year

Field vintage is preserved separately from publication and source-revision metadata.

Geographic scope

Only exact county FIPS 27171 and 27053. Tract-to-county aggregation is not performed implicitly.

Missing values

N/A, blank, -9999, -8888 and suppressed entries remain missing; none become zeros.

A clean schema check does not establish that the publisher supplied the values or that a policy conclusion follows.
