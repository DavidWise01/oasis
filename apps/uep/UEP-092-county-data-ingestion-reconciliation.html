Detected CSV schema

Upload a CSV and select Inspect. The first few columns and source fingerprint will appear here.

Validation rules

A number must be finite and nonnegative for supported count/rate fields. Rates cannot exceed 100%. County extraction requires a known FIPS column or separate state/county FIPS fields. A valid file hash authenticates the imported bytes within this browser session; it does not independently certify the publisher or accuracy of reported values.

Unsupported shortcuts

Do not rename older LRAM as new SRAM, relabel 2022 field values as 2026, or substitute a food-shelf-visit total for the number of food-insecure residents. Source records are appended, not silently replaced.
