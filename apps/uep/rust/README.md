# OaSIs UEP Rust kernel

Phase X migration scaffold, source anchored to UEP-200 (commit 0bdfb7db06f1eb771c6e1bfc7c61a05ebceb8a6b).

```sh
cargo test --manifest-path apps/uep/rust/Cargo.toml
cargo run --manifest-path apps/uep/rust/Cargo.toml
```

Dependency-free integer state transitions, aggregate universal arrears, local inventories, physical harm and independent repair funding. Fixed population; no transfers, individual lots, restoration, maintenance, uncertainty optimizer or adaptive gate yet. This is a new simplified long-horizon kernel, not a parity port of UEP-199. No actual transactions. Historical HTML remains untouched. Future browser integration requires a WASM build and adapter; not included.
