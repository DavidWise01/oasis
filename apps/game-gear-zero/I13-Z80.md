# I-13 x GG-ZERO — executable Z80 signed-trit adapter

**Status:** original 16 KiB Game Gear Z80 cartridge implemented, page-level integration verified. This is **not** the complete canonical I13-H1.1 compiler or 15-opcode VM.

The canonical I-13 surface is **I + twelve semantic words**, not arbitrary symbolic multiplication:

    I, Name, Constant, Attribute, Assign, Arg, Return, Expr,
    If, Compare, Call, FunctionDef, BinOp

Canonical historical 15 VM opcode names (registry only in the GG adapter):

    Const Ask Attr Ret Answer Drop Bin Cmp If Call Block Else End Func Halt

These names appear in the generated ROM's JS metadata; **the cartridge does not interpret all 15 opcodes**. The canonical VM uses \`f64\`, whereas this Z80 adapter deliberately uses a bounded signed 8-bit trit with -1 encoded as 0xFF. No invented compatibility with the full I13 surface.

## What really executes on Z80

\`games/i13-kernel.js\` assembles one standalone \`.gg\` ROM. The program:
1. Boots at reset vector \`0000h → 0100h\`, installs an interrupt service routine at \`0038h\`, enables the VDP.
2. Copies its own tile, CRAM palette and name-table data through real Z80 \`OUT\` instructions to Game Gear VDP ports.
3. Enables Game Gear VBlank and samples active-low controls on emulated port \`0xDC\`.
4. Runs the exact \`E1.TECH-001\` trit authority law inside Z80 instructions:

       if evidence_trit == -1 -> -1 (HOLD)
       else if question_debt > 0 -> 0 (FLAY)
       else if evidence_trit == +1 -> +1 (PROCEED)
       else -> 0 (FLAY)

5. Rejects evidence outside -1/0/+1 with a negative HOLD and a separate invalid-input marker. An accepted -1 is still a **valid input**, not a parser error.
6. Writes a verdict to RAM and changes the Game Gear CRAM through Z80 I/O, producing a genuinely VDP-derived red, amber or green field on the 160 × 144 LCD.
7. Logs an evaluation count and serviced VBlank count in RAM; the web page only *reads* those results.

## Controller mapping

| Key | Cartridge behavior |
|---|---|
| Left | evidence = -1, HOLD |
| Up | evidence = 0, FLAY |
| Right | evidence = +1, PROCEED candidate |
| Button 1 / Z | increase question debt, capped at 3 |
| Button 2 / X | clear question debt |
| Down | reduce question debt toward 0 |

Inputs are sampled by the Game Gear Z80. The UI buttons do **not** assign verdicts directly.

## Hardware receipt registers

| Game Gear address | Meaning |
|---|---|
| \`C100\` | signed evidence trit (0xFF, 0x00, 0x01) |
| \`C101\` | bounded question debt (0–3) |
| \`C102\` | evaluated verdict (0xFF, 0x00, 0x01) |
| \`C103\` | input guard: 0x01 valid / 0xFF veto |
| \`C104\` | previously painted verdict, to skip redundant VDP writes |
| \`C105\` | evaluation counter (8-bit rollover) |
| \`C106\` | raw sampled \`0xDC\` input |
| \`C10E\` | VBlank ISR count (8-bit rollover) |
| \`C10F\` | \`0xA5\` cartridge boot success |

The **input guard is not the full Cortex Verifier (CV)**. E1 return/capsule verification, E1ID, OLOGY vector-rooted voxels, compiler normalization and full VM execution are not implemented by this adapter.

**Safety/authority:** \`+1\` is only a signed-trit result. It does not grant filesystem/network/repository or other host capabilities. No host operations occur in the cartridge.

## Tests

\`node tests/i13-kernel.test.js\` passes **25/25** isolated tests:
- nine combinations from valid evidence (-1,0,+1) and question debt (0,1,3);
- three invalid-evidence veto inputs;
- correct red/amber/green CRAM writes and 160x144 framebuffer;
- Z80 VBlank handler, input-port-derived changes and guard recovery after rejection;
- first boot and I+12 words / 15 historical opcode metadata validation.

Additionally an instrumented **page-level simulation** loaded the live \`index.html\`, clicked **RUN I-13 ON Z80**, pressed Left, Right, Z, X, Up and checked ROM RAM + on-glass lamp colors and event ledger. It subsequently launched First Light, which still booted normally.

These tests do not establish full Z80 instruction compatibility on arbitrary cartridges, or full I13-H1.1 parity. They also do not verify a physical Game Gear or native speaker.

## How to run

Open [GG-ZERO GitHub Pages](https://davidwise01.github.io/oasis/apps/game-gear-zero/), then click **RUN I-13 ON Z80**. Use the controller. The CPU/VDP/PSG inspector and I13 register panel update as the ROM runs.

Choose **DOWNLOAD I-13 .GG** to export the actual 16,384-byte cartridge. It's generated client-side from our own Z80 assembler; no commercial Game Gear ROM or BIOS is included.

The earlier working **First Light** baseline is preserved on branch
[\`freeze/gg-zero-first-light-v0.2\`](https://github.com/DavidWise01/oasis/tree/freeze/gg-zero-first-light-v0.2).
