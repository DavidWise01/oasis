# ROOT0 P4.38 — authenticated IPC gate / same-host regression (2026-10-10)

Executed locally on Node.js v22.16.0: **16/16 assertions PASS**, final test elapsed **109.143 ms**. P4.38 uses an Ed25519-signed, domain-separated IPC request envelope (client ID, nonce, action, deployment, signed intent). The witness process checks a configured pinned controller public key and persists consumed nonces in SQLite. A real witness SIGKILL and restart left nonce replay rejected. Only READ and CAS operations are exposed; the self-contained P4.34 CAS gate enforces monotonic signed intents. In 20 competing signed CAS submissions exactly one new branch won and the other 19 were rejected. Wrong client ID, altered/invalid intent, raw SIGN action and unauthorized future epoch were refused.

**Caveats:** This is application-level authentication over Node parent-child IPC **on the same host/OS identity**, not independent user IDs or host trust. The owner signing private key is available to the test harness, and the witness key/database and auth ledger are all held under one host's administrative control. Nonce reservation precedes CAS so an interruption can deny a legitimate retry; nonce ledger is currently unbounded. This does not establish independently protected anti-rollback or production security. Prior local code error handling a public-key KeyObject was repaired before final rerun.
