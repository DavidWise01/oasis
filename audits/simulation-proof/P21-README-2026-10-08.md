# ROOT0 P2.1 — Physical-bridge nonuniqueness proof test

Run:

```bash
python p21_underdetermination_test.py
```

Files `kernel.py` and `CANON.json` are unmodified frozen source copies, with Git-blob and SHA-256 checks in the runner. The executable writes `p21-results.json`. The additional physics calculation is a strictly-stable three-dimensional *scalar-wave toy attachment*, not a property already established by the frozen kernel. Both `a=2l_P` and `a=3l_P` preserve identical symbolic evolution but differ in predicted dimensionful time delays.

`P21PhysicalBridgeCountermodels.lean` is a formalization draft and must be compiled independently. This test does **not** establish simulation theory.
