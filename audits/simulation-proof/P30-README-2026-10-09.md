# ROOT0 P3.0 — Signed Wavelength/Amplitude Interaction

**Carrier:** `{-e{ ..||..|....||| }+e}` (exact literal). This is a newly specified *model-local* interaction layer attached to the existing P2.9 100-million-address reality tensor. The frozen v92 canon is unchanged.

## Run

- Open **`index.html`** in a browser. It is self-contained: no network, imports, build tool or remote assets required. It has wavelength, amplitude, phase kick and coupling controls; edit the square/round addresses, then click **Initialize** to apply parameter changes.
- Run **`node test_wave.mjs`** with Node 22+ to recheck 20,000 random gate/inverse tests, the full 100-million-address transpose check, and an executed fourteen-tick forward/reverse branch. It creates `P30-results.json`.
- `tensor_kernel.mjs` is the **unaltered P2.9 reversible router**; `wave_kernel.mjs` adds a sparse complex field and a reversible signed-port phase mixer. `build_wave_explorer.py` constructs the self-contained UI from their exact source modules.
- `test_browser.py` is a Playwright automation check; it uses system Chromium if installed. This is optional and not necessary to run the explorer.

## Topology

A tensor coordinate is `(outer, inner)` with each index in `0…9999`. The square/round coupling pairs `(outer, inner)` with `(inner, outer)`. There are 49,995,000 off-diagonal unordered pairs and 10,000 fixed diagonal addresses. `Complex[0]` is `(0,0)` and is prohibited from carrying a changing wave amplitude.

## Signed motif and added policy

The motif has six runs: `..`, `||`, `..`, `|`, `....`, `|||`, totaling **8 dots and 6 bars**. In the *candidate model*, each dot advances phase by `2π/λ`, each bar adds a configurable phase kick `κ`, and `-e/+e` denote opposite conjugate phases at two coupling ports. **No claim is made that the dots physically encode time, that the bars are actual gates, or that `e` denotes measured electric charge.**

`A` sets initial complex wave amplitude. Coupling angle `θ` sets how much amplitude flows between paired addresses. The update is complex-unitary before optional floating-point sparsification. See `REPORT.md` for the exact equation, proof sketch and limitations.

## Scope

Executable proof of computer-model invariants, **not** a derivation of photons, Maxwell dynamics, quantum measurement, or proof that external reality is simulated. Lean draft is not compiler checked.
