Reproduction with Node 22:

```bash
node p18_conditional_history.mjs
```

The program pins the original Git blob, runs the source T2 test, proves the finite maximum predecessor multiplicity by exhaustive enumeration, and checks 55,296 20-step reversible traces using the minimum worst-case 2-bit predecessor rank. It generates `P18-results.json` and prints its JSON output.

`P18ConditionalRecovery.lean` is a separate Lean 4 draft. A CI proof gate targets Lean 4.33.1. The workflow result must be checked on GitHub before asserting that Lean compiled.

**This is a symbolic mathematical result, not a physical observation of our universe.**
