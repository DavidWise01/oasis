Worlds & boundaries

Register an external agent

An agent entry describes an adapter and capabilities. Registration does not call, grant access to, or run an external model.

Witness ledger

Local browser storage, hash-chained event records. No cloud synchronization or real distributed consensus.

    Founding runtime boundaries

    Agents may observe, propose and build inside assigned spaces. Proposals do not mutate durable truth. A separate human action commits witnessed proposals. The append-only log retains lineage, and a missing or invalid witness produces HOLD. Root/frozen parent remains outside this browser simulation.
