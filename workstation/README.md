# OaSIs Art Workstation

Offline-first, single-page art workstation built on the Root0 Arch semantics.

## Arch

```text
|    isomorphic OSI boundary
||   immutable human/carbon attachment
|||  full Neon engine
00   Root0
```

## Workstation features

- freehand brush and eraser
- lines, rectangles, circles, text
- deterministic Neon lattice generator
- Pocket Prime generator
- Ouroboros / OSI 00–10 generator
- Root0 glyph and PER/CEPT/ION primitives
- undo / redo / grid
- local browser save/load
- PNG export
- private project JSON export
- public provenance export that omits private pocket notes and canvas state
- creator / carbon / source-token / license / contribution / optional payment metadata

Open `index.html` directly in a modern browser. No server or external dependencies are required.
