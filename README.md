# Energy Titan · Sapien Six Channel · GitHub Pages

Static deployment of the offline, self-contained six-channel WASM simulation at https://davidwise01.github.io/oasis/.

Source (frozen app release): https://github.com/DavidWise01/oasis/blob/main/apps/ket-energy-titan-sapien-six-channel-3d-wasm-v06/index.html

The app simulates six logical wireless channels and cellular toroidal state; it does not wirelessly charge real phones.

Pages content is intentionally **only** a single self-contained executable document plus metadata. The KET v2.0 frozen kernel remains pinned to de8f8b80aba3a73dd371811f6b4be39df92e45ce and is not included or modified here.
