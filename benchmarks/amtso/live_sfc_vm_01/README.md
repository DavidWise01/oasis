# Juliet / Mandel AMTSO Live SFC VM 01

Open `launcher.html` in a browser.

For each test:
1. Open the official AMTSO test page.
2. Run the AMTSO feature check.
3. Record the result in the local launcher.
4. Export the evidence JSON when finished.

The six checks are:
- Manual EICAR download
- PUA detection
- Compressed EICAR
- Drive-by EICAR
- Phishing page
- CloudCar cloud lookup

This package contains no live malware and makes no certification claim.
