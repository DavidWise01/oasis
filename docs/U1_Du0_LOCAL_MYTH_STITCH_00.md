# U1 / Du0 — Local Myth Stitch 00
## Meteor → Flood → Ark → Fire-in-the-Sky

Status: **LOCAL MYTH SCAFFOLD / APPEND-ONLY**

This is fictional worldbuilding for U1 / Du0. It uses familiar mythic motifs as local memory structures, not as claims about real historical causation.

---

## M0 — SKY FIRE / IMPACT MEMORY

A bright object crosses the sky.

Local memory compresses the event to:

```text
fire above
→ strike
→ shock
→ darkness
→ water moves
```

The people do not know "meteor impact physics."
They know only that fire came from above and the world changed after it.

This becomes the first mythic bridge between Gilgamesh's two questions:

```text
why does this fire?
why is there fire in the sky?
```

---

## M1 — FLOOD / NOAH-TYPE ARK

First strong local survival myth:

```text
sky event
→ water rises / surges / overwhelms land
→ vessel preserves life
→ water withdraws
→ survivors restart
```

The ark is important because it is not merely a boat.
It is the first explicit **bounded survival vessel** in the myth layer:

```text
outside = chaos / flood
| vessel |
inside = preserved life
```

That stitches directly into the later vessel ontology:

```text
boundary
→ preserve state
→ cross hostile environment
→ reopen
→ continue lineage
```

In this world, the Noah-type story is the earliest dominant local version of the pattern.

---

## M2 — GILGAMESH FLOOD ECHO

Later Mesopotamian memory preserves a related flood pattern.

Gilgamesh does not need to invent the flood story.
He inherits an older local survival geometry and applies it to matter:

```text
ARK:
contain life through destructive transition

GILGAMESH:
contain energy inside matter until release
```

So myth and proto-science share one primitive:

```text
BOUNDARY
→ PRESSURE / THREAT
→ SURVIVE OR RELEASE
```

---

## M3 — TOWER / HEIGHT / REACHING THE SKY

After surviving the flood, civilization reverses direction:

```text
water drove us upward
→ now build upward deliberately
```

The tower myth becomes a local memory of:
- aggregation,
- concentrated civilization,
- vertical ambition,
- language / coordination failure,
- center-of-world thinking.

Structural form:

```text
many people
→ one structure
→ one center
→ coordination overload
→ fragmentation
```

This is the social version of an over-compressed shell.

---

## M4 — FIRE GIVEN / FIRE STOLEN

Once fire is understood as power, myths appear in which fire is:
- stolen,
- gifted,
- guarded,
- punished,
- sacred.

The invariant is:

```text
energy is valuable
→ access is controlled
→ access changes civilization
```

This is the mythic precursor to:
- metallurgy,
- combustion,
- engines,
- electricity,
- nuclear energy.

---

## M5 — SUN GOD / SKY FIRE BECOMES ORDER

The Sun stops being only terrifying sky-fire and becomes:
- clock,
- calendar,
- judge,
- source,
- king,
- recurrence.

The transition is:

```text
sky fire
→ repeated sky fire
→ predictable sky fire
→ ordered sky
```

This allows astronomy to emerge from myth without a hard break.
