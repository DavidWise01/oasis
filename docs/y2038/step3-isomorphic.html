Step 3: carry time
without losing identity.

Versioned 16-byte packet, big-endian, explicitly sized. The source remains signed Unix seconds; the encoded envelope carries daily turns and within-day seconds. A spinor parity bit is derived and checked. A receiving 32-bit port must reject values outside range.

04 / Wire invariants

Envelope: IT3 v1 · exactly 16 octets
turns = floor_div(unix_seconds, 86400)
phase_seconds = unix_seconds - 86400 * turns
parity = turns mod 2 (normalized 0 or 1)
phase_field = (parity << 31) | phase_seconds
seconds = turns * 86400 + phase_seconds
spinor = +1 if parity = 0, else -1

Reject if:
  unknown version / wrong length / reserved bits set
  phase_seconds >= 86400
  parity does not equal turns mod 2
  reconstructed seconds outside signed int64
Legacy port rejects seconds outside signed int32.

The 64-bit turns field permits encodings whose reconstructed seconds exceed int64; such packets are invalid and must be rejected. This is an application-level format proposal, not a standardized Unix ABI.

05 / Deployment rule

Negotiate support before sending IT3 packets. Never send this new binary layout to an unchanged legacy client and assume it understands it. Keep explicit schema versions, migrate stored fields deliberately, and retain the original second count when crossing APIs.
