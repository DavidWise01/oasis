02 / Step 1: enforce 64-bit time

For supported 32-bit Linux/glibc builds, these macros request 64-bit time interfaces. The compile-time assertion catches unsupported configurations.

#define _FILE_OFFSET_BITS 64
#define _TIME_BITS 64
#include <stdint.h>
#include <stdio.h>
#include <time.h>
#include <inttypes.h>

_Static_assert(sizeof(time_t) >= 8,
               "Y2038 unsafe: time_t must be >=64 bits");

int main(void) {
    time_t now = time(NULL);
    if (now == (time_t)-1) {
        fputs("Clock read failed\n", stderr);
        return 1;
    }
    printf("Unix timestamp: %" PRId64 "\n", (int64_t)now);
    printf("time_t width: %zu bits\n", sizeof(time_t) * 8);
    return 0;
}
Get time64.c

03 / Compile and run

Run the following from the folder containing time64.c.

cc -std=c11 -Wall -Wextra -Werror time64.c -o time64
./time64

Expected: the program prints the current Unix timestamp and a time_t width of at least 64 bits.
