03 / Exact reverse walk
{{i::time::reverse::v1}}
  read ← /vogel/voxel/vector/sda/{drive}

  {drive} = immutable 16-byte payload
  sda     = logical block + byte offsets
  vector  = (index, byte) ordered pairs
  voxel   = (x=index%4, y=index/4, z=byte)
  vogel   = 4×4 geometry projection of voxels

  reconstruction:
    index = 4*y + x
    payload[index] = z
    decode_IT3(payload) == original_seconds

  guard = reject malformed packet
  spinor = derived parity witness
  identity = byte-exact, not approximate
The word sda labels the logical storage boundary in this educational pipeline. The browser never writes physical disk sectors. The geometric rendering is deliberately non-authoritative and may be changed without changing the packet.
