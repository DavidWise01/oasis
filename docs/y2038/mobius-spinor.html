Arcseconds on a
Möbius spinor.

One daily revolution advances the angular clock by 360° and flips the spinor sign. A second revolution returns the sign at 720°. The integer revolution count never disappears, so time remains reversible.

Live Möbius surface

The surface is a 3D visualization of the Möbius topology. The spinor sign is a modeled double-cover state, not evidence of microscopic spin or a cure for 32-bit ABI overflow.

The invariant

{{i::time::mobius::spinor}}
  epoch = unix_1970_utc
  seconds = signed_integer
  arcseconds = 15 * seconds
  daily_turns = floor(seconds / 86400)
  phase_seconds = mod(seconds,86400)
  spinor = (-1)^daily_turns
  closure = 2 turns / 720deg

The sign is derived from the revolution count. It does not replace or compress that count.

Lossless decoder

seconds = daily_turns * 86400 + phase_seconds
0 <= phase_seconds < 86400
spinor = +1 for even turns, -1 for odd turns

arcseconds = seconds * 15
phase_arcseconds = phase_seconds * 15

At the Unix 2038 boundary, the total time value stays 2147483648. This encoding preserves it, but every legacy 32-bit software interface still requires a widened representation or guarded rejection.

Next engineering boundary

Specify a portable binary envelope for signed revolution count plus unsigned phase; verify round trips through serialization. Angular topology belongs to the representation layer; platform time APIs still need 64-bit values.
