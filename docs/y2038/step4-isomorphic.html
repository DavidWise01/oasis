05 / Verification boundary

The full chronology requires the signed daily-turn count; the Möbius orientation parity alone cannot uniquely encode time. A signed 32-bit receiver must still reject timestamps outside its valid range. Step 4 does not substitute for migrating existing database fields or APIs.
