04 / Reversible conversion rules
DAY = 86400
turns = floor_div(seconds, DAY)
phase_seconds = seconds - turns * DAY
phase_arcsec = 15 * phase_seconds
spinor = +1 if turns is even else -1

decode(turns, phase_arcsec):
    require 0 <= phase_arcsec < 1296000
    require phase_arcsec % 15 == 0
    return turns * DAY + phase_arcsec / 15

legacy32(seconds):
    require -2147483648 <= seconds <= 2147483647
    otherwise return REJECT
The spinor state is redundant verification metadata. Keeping the full turn count makes the mapping invertible, including timestamps before the epoch.
