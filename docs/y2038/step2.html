03 / Correct boundary behavior

#include <stdint.h>
#include <stdbool.h>
#include <limits.h>

bool to_legacy_i32(int64_t seconds, int32_t *out) {
    if (!out || seconds < INT32_MIN ||
        seconds > INT32_MAX) {
        return false; // reject, do not truncate
    }
    *out = (int32_t)seconds;
    return true;
}

For an actual wire protocol, define byte order and field width explicitly. This helper only guards the numeric conversion.

05 / Real repository search

From your project root, review references to narrowing casts, format strings, legacy fields, serialized timestamps, and 32-bit API assumptions. Inspect every match manually.

git grep -nE 'time_t|int32_t|uint32_t|time32|timestamp|strftime|mktime|localtime|gmtime|%d|%ld' -- '*.c' '*.h' '*.cpp' '*.hpp'

The search is intentionally broad: it is an inventory, not an automated vulnerability verdict. For binary storage and external data contracts, document the schema and supported range.
