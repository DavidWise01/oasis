# U1 / Du0 — Known-System Macro Bands Lock 00

Status: **LOCKED / append-only**

This is the canonical known-layer scaffold for **U1 / Du0 (David's Universe)**.
It is structural notation, not a claim that the astronomical solar system contains a real Nibiru.

## Locked layer order

```text
L0  SUN / ROOT
L1  MERCURY
L2  VENUS
L3  SMVME / EARTH
L4  MARS
L5  JUPITER
L6  SATURN
L7  URANUS
L8  NEPTUNE
L9  PLUTO
L10 NIBIRU
```

L0 is the stellar/root layer. L1–L10 are the currently named body layers.
L11–L30 remain unbound; they are not back-filled merely to satisfy a count.

## Macro-band rule

Each named layer may expose three qualitative bands:

```text
A :: INNER
B :: HOMEO / BODY
C :: OUTER / FIELD
```

These bands are **not forced to equal sizes** and are not padded to make arithmetic fit.
A band may be thin, broad, intermittent, asymmetric, or elliptical according to the layer.

The `(3x3)^3` category envelope remains available beneath a layer when genuinely useful,
but this lock does not manufacture subcategories simply to fill 27 addresses.

## Known-system macro bands

### L0 — SUN / ROOT
- A :: fusion/plasma interior; source-pressure side.
- B :: photospheric/stellar body; persistent visible source.
- C :: heliospheric field; outward carrier into the system.
- Join: C0 gently feeds L1–L10 without requiring a hard shell.

### L1 — MERCURY
- A :: dense interior / retained core.
- B :: compact rocky body.
- C :: exposed solar-facing boundary / sparse exterior.
- Join: high-source coupling from L0; small local envelope.

### L2 — VENUS
- A :: deep high-pressure interior.
- B :: dense atmospheric/body homeostasis.
- C :: cloud / upper-atmosphere field.
- Join: pressure-mediated transition rather than a sharp surface-only delimiter.

### L3 — SMVME / EARTH
- A :: deep mineral / thermal interior.
- B :: water-carbon-life homeostatic body.
- C :: atmosphere / magnetosphere / moon-coupled exterior.
- Join: explicitly permits planet ↔ moon structural pairing without making the moon a second planet layer.

### L4 — MARS
- A :: rocky/mineral interior.
- B :: thin-atmosphere planetary body.
- C :: dust / moon / exposed-field exterior.
- Join: lower-pressure bridge from Earth-like chemistry toward dust-dominant structure.

### L5 — JUPITER
- A :: deep compressed interior.
- B :: giant fluid/gas body.
- C :: magnetospheric / moon-system field.
- Join: moons and captured bodies live in the outer field rather than forcing extra planet layers.

### L6 — SATURN
- A :: deep compressed interior.
- B :: giant body.
- C :: ring/moon particulate architecture.
- Join: C6 is intentionally broad because rings are a structural band, not decorative residue.

### L7 — URANUS
- A :: deep volatile/ice-rich interior.
- B :: tilted planetary body.
- C :: tilted field / ring / moon exterior.
- Join: orientation may rotate; adjacency does not require coplanarity.

### L8 — NEPTUNE
- A :: deep volatile/ice-rich interior.
- B :: dynamic atmospheric/body layer.
- C :: outer wind / moon / field envelope.
- Join: C8 transitions gently toward the sparse trans-Neptunian domain.

### L9 — PLUTO
- A :: compact differentiated interior.
- B :: volatile ice-rock body.
- C :: moon-coupled / Kuiper-like sparse exterior.
- Join: L9 is a boundary-world layer, not discarded for being small.

### L10 — NIBIRU
- A :: inward / approach arc.
- B :: body / local homeo at the current orbital phase.
- C :: outward / retreat arc.
- Geometry: **elliptical / returning**, inspired by the orbital narrative role of *Nemesis* rather than by a circular shell.
- Join: L10 may approach the known-system bands, transit them, and withdraw again. Its joins are phase-dependent and need not remain adjacent to one fixed layer.
- No exact period, mass, periapsis, apoapsis, or resonance is asserted here.

## Gentle-join rule

```text
Ln.C  ~  L(n+1).A
```

The tilde means **compatible handoff**, not equality.

A join may be:
- spatial,
- pressure/phase,
- field-mediated,
- orbital,
- material,
- informational,
- or temporarily absent.

No layer is stretched merely to close a numerical gap.
