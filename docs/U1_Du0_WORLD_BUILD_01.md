# U1 / Du0 — Full World Build 01

Status: **APPEND-ONLY WORLD BUILD**

U1 / Du0 is a fictional/speculative world-model. Its internal logic is designed to be coherent across myth, history, astronomy, technology, and OaSIs structure. It is **not** presented as empirical proof of Nibiru, engineered humanity, a prison planet, or a hidden real-world history.

## Root name

```text
U1 / Du0
David's Universe
-mObiUs
```

`-mObiUs` means: **end where you started; change the middle.**

The same Terra persists through each pass. The route, scars, myths, technology, and memory change.

## Six channels

```text
C1 :: MYTH
C2 :: OBSERVED
C3 :: AUTHORITY
C4 :: SACRED / INTERPRETED
C5 :: MODEL / WORKING SCIENCE
C6 :: HIDDEN PROVENANCE
```

All historical scenes are read through all six channels. A culture can have true observations, false explanations, useful models, sacred interpretations, institutional authority, and compressed myths at the same time.

The Superman / Ka-El pattern is used structurally: a made child survives a damaged parent world, arrives elsewhere, and eventually asks why the parent made him. It is an archetypal analogy, not a claim about Superman canon.

## Terra doctrine

Gilgamesh-era root:

```text
AS BELOW
SO ABOVE

bounded thing
→ shell
→ pressure / binding
→ TERRA
```

The early error is useful: spatial center, observer/reference center, and homeostatic center are treated as the same thing. Earth therefore becomes the center of 'above' because terra is the center of 'below.'

Galileo-era correction:

```text
spatial center
!= reference center
!= homeo center
```

The invariant survives while the coordinate changes.
