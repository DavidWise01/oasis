# TESSY · BOXY — STATE / SPACE / TIME MACHINE

**SST v1.0 · 2026-10-18.** Locked grammar + documented extensions; executable symbolic language, not verified quantum physics.

`{{ TESSY :: x:STATE :: y:SPACE :: z:TIME :: |||| :: INTENT → GEOMETRY → FUNCTION }}`

---

## 01 — Canonical coordinates

| Axis | Exact meaning | Model record |
|---|---|---|
| `x` | **STATE** | Scalar condition/rolled-up kernel |
| `y` | **SPACE** | Where or when an operation occurs |
| `z` | **TIME** | What happened (ordered event) |

Do not replace these meanings with textbook XYZ conventions. Optional three-register notation `0k / 1k / 2k` means nothing / something / something else in the user's model.

## 02 — Enclosure and primitives

`||||` bounds **all** operations; `.` identifies a vector or transfer point; straight strokes carry connections; `−/+` encode direction/reversal. Three vectors and three lines form a reusable triangular primitive, composable into more complex shapes. The symbolic **1131** process reads 1 origin / 1 rollout / 3 fold components (two sides/top) / 1 closure; it does not describe a literal six-faced cube construction.

## 03 — The complete case-sensitive alphabet

Every `A–Z / a–z` glyph is a potential function based on **intent + connected geometry + state**, never automatically a fixed English expansion. Example readings: H=harness/highway/hookup; T=transport/transfer; P=pulse/portal/pocket; S=switch/select; E=excite/emit; L=load/link. A proposed `HTPPS` word means an ordered accepted sequence; a loop reading is valid only if the transfer paths actually reconnect. The graphic prototype has 26 stroke shapes with upper/lower variants. Do not conflate stroke count with the number of graph edges after subdividing junctions.

## 05 — Transform and transfer

**Four quadrants, 90° each**: A=0°, B=90°, C=180°, D=270°; the next turn returns to 360°. Reverse/mirror, upside-down and inside-out are separate operations. Transform coordinates but preserve A/B/C/D identities; transfer destination is a named point, not an assumed physical electron trajectory. Earlier eight × 15° and four × 15° iterations were corrected and are **not canonical**.

## 06 — Intent-first foundation grammar (locked)

1. Open a `||||` box; select one upper/lower-case root letter and **LOCK** it as foundation/intent.
2. Evaluate **one** candidate letter on top of the accumulated foundation.
3. **LOCK** accepts and appends the candidate; **DISCARD** rejects it while preserving its decision record.
4. Repeat as many times as appropriate; original bottom letter continues setting the tone.
5. When no candidate is unresolved and the operation is complete, emit `✓`.
6. Emit contextual delimiter `X` between checked foundations and start a fresh box. Ordinary `X` inside a word is still a glyph.

`{{ ROOT LOCKED :: CANDIDATE → LOCK / DISCARD :: ✓ :: X }}`

No arbitrary word length. A checked foundation is closed, not editable.

## 09 — Time and provenance

Use exact corrected d-operators: `-d` **past/read-verify**, `-d+` **present/evaluate**, `+d` **future/append**. Three independent evaluations: *generative? agentic? accurate?*, each Y/N/unknown according to evidence. Older temporal `p− / −p+ / +p` is a separate notation and must not be overwritten by provenance d-operators. Time `z` records what happened, not necessarily a physical clock interval.

## 10 — Hash, duplication, and repetition

Canonicalize records before hashing. SHA-256 may deduplicate equal **bytes** while recording all independently grounded origin paths. Same content in different contexts can be revisited repeatedly without duplicating the physical data or manufacturing independent witnesses. A Merkle root commits leaves for integrity but does **not** prove truth. The suggested **17 FLAY passes minimum** is a separate, unvalidated analytic setting; it must not be conflated with 17 state changes or independent corroborations.

## 11 — Transport / electronics analogy and limits

The dot is a point or junction, the line is a possible road, the wall `|` a bounded condition. `.|`, `..|`, `...|`, `.:|` were explored as pinball/excitation/threshold metaphors. The 555 timer analogy supplies trigger, threshold, capacitor charging and discharge, clocking or reset; it does not prove electrons literally drive along glyph letters. The `{{3×3}}³ = 729` address count is a symbolic combinatorial capacity, not a measured concurrent charge. A ten-layer extended OSI analogy and proposed seventeen-step traversal remain proposals. `[3 7 0]` and nested shell notation are not evidence of quantum advantage.
