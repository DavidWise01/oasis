# ROOT0 corpus → TESSY QUANTA alignment · v1

**Mode:** additive adapter. Never rewrite existing frozen source inventories, source conclusions, or canonical Tessy foundations.

## Verified input boundary
- `ROOT0_MASTER_DISCOVERY_20261018.json`: **2,144** GitHub repository metadata records, not full file content and not independent physical observations.
- Each input repository is a `source` with evidence level `REPOSITORY_METADATA_ONLY`, `observed=false`, `verified=false`. Descriptions and URLs are metadata, not automatically true claims.
- The source registry remains intact. A source may be linked to multiple independent observations later without copying/duplicating the underlying repository metadata.

## Quanta semantics
```
{{ CORPUS → OBSERVE → RECORD → ESTIMATE → PREDICT → WITNESS → UPDATE }}
0 @[v,w,x,y,z] :: PINNED
x :: STATE  y :: SPACE  z :: TIME / WHAT HAPPENED
-d :: past/read   -d+ :: present/evaluate   +d :: future/append
```
1. `align(registry)` produces a deterministic addressable set of source metadata; **zero** empirical observations are invented.
2. `observe(source,event)` requires event ID, original evidence and event time; evidence quality must be assessed separately.
3. `estimate(outcomes)` validates *user-supplied* normalized probabilities. There is no fabricated statistical estimator or calibrated forecast without training data.
4. `predict(id,distribution,observation)` freezes a prediction reference tied to prior observation.
5. `witness(prediction,state,evidence)` requires an event identifier different from the original; evidence provenance and independence still require external evaluation.
6. `update(prediction,witness)` records predictive surprisal in bits and does **not** silently update the model. Model calibration is a future stage requiring real repeated observations.

Colors (1–370) are optional visualization addresses from the uploaded registry, not new evidence and not physical wavelengths. The locked foundation, 52 case-distinct glyphs, four 90° phases, BOXY and A/B/C/D transfer identities remain unchanged.

## Tests
`node docs/mnp-3d/test-quanta-corpus-v1.cjs` checks inventory, pinned observer, provenance guards, probability validity, temporal evidence separation, outcome scoring and no model mutation.

**Out of scope:** claiming 2,144 samples of phenomena; quantum physical validation; inference from repository names alone; treating a Merkle hash as truth; counting repeated content as independent corroboration.
