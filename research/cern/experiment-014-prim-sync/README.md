# PRIM Experiment 014 — 4 vectors × 3 oscillators

Four fixed radial arms with 3 phase-oscillator segments each; eight within-arm bonds plus four hub-ring bonds. No physical rotation. Classical Kuramoto-type phase dynamics, tested via scipy solve_ivp DOP853. 2 frequency-disorder regimes × 6 coupling configurations × 8 seeds = 96 simulations. At natural frequency SD 0.15 and within-arm coupling 0.5: no hub coupling yields mean global coherence 0.48922; hub coupling 0.5 yields 0.87635; hub 1.0 with within-arm 1.0 yields 0.96989. At equal frequencies, strong hub coupling yields near perfect coherence. Each arm can synchronize internally before the complete array synchronizes. Locked criterion checks temporal variance of relative phases and should not be interpreted as all phases equal. This is a classical oscillator model, not photon interaction evidence.
