# PRIM Experiment 025 — Common-mode inference

2026-10-23. Simulated 64 observation paths and 6000 trials at noise sigma=0.06 rad. Shared noise fractions rho=0,.01,.1,.5,1. Baseline averaging compared with independently measured common disturbance, reference noise 0.005 or 0.02 rad. At rho=1, baseline RMSE 0.05985996 rad; 0.005-rad reference RMSE 0.00509156 rad. At rho=0, reference worsens RMSE from 0.007539 to 0.009078 rad. With equal common signal and disturbance, sibling differencing cannot identify either component. **Important**: reference sensor is assumed to measure common disturbance independently of the true phase; deriving such a reference from only the existing paths is not demonstrated. No phase dynamics or CERN photon data. Source code and results available in ChatGPT prim_exp025 package.
