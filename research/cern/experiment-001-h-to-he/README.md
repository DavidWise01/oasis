# Experiment 001 — H → He (pp-I)

Status: educational nuclear conservation and mass-energy baseline; not an LHC event reconstruction or discovery.

Solar pp-I chain:
- 2 × (p + p → D + e+ + νe)
- 2 × (D + p → ³He + γ)
- 1 × (³He + ³He → ⁴He + 2p)
- 2 × (e+ + e− → 2γ)

Net: 4p + 2e− → ⁴He + 2νe + 6γ.

Using neutral atomic masses m(¹H)=1.00782503223 u and m(⁴He)=4.00260325413 u:
Q = (4*m(¹H)-m(⁴He))*931.49410242 = 26.730970 MeV.
Neutrinos escape with some of this energy.

Validated locally: conservation of baryon number, electric charge, and electron-lepton number in 4 reaction types; net balance; Q sanity range. Full runnable Python script in downloadable experiment archive in ChatGPT conversation.

Caution: CERN's high-energy p-p collisions are different from the stellar proton-proton fusion chain. Next task is separate real collision event reconstruction from CERN Open Data.
