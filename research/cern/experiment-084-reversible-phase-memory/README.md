# PRIM 084 — Reversible Josephene phase memory

The 24-phase, 60-unit Josephene test preserves exact rational branch register `s=m+j+p`, `d1=m-j`, `d2=j-p` and finite-precision phase register `n=floor(phi/2π), theta=phi−2πn`. Inversion recovers m,j,p exactly and reconstructs phi within numerical tolerance. Simulates 24×60×100 = 144,000 Euler integration steps; 576,506 checks pass. Final winding values 5 and 6. The 60-unit beat and 16-position register jointly realign after 240 units. `test.py` in this directory is the executable regression; conversation ZIP contains a fuller test with CSV/JSON outputs. Overdamped RSJ is idealized: energy bookkeeping is algebraically balanced by the modeled definitions, not independent experimental verification.
