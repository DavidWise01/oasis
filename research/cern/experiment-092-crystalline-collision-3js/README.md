# PRIM 092 — Crystalline Collision Observatory (Three.js)

Interactive standalone `index.html` Three.js scene. Features two electrum (Au–Ag) wraps, translucent Ice IX layers, NaCl cores, rotating dust halos, fracture markers, ejecta field, toroidal aftermath, orbit camera and eight collision phases. Time scrub, Run/Pause, step, adjustable playback speed and impact parameter, selective material layer visibility, and three separate A1/B1/C1 what/how/why witness reports; seal for human review. Uses Three.js 0.164.1 and OrbitControls from jsDelivr CDN, so requires connectivity for initial library load and WebGL browser support.

**Run:** open `index.html` using GitHub Pages on a configured branch, or host as a static website. If ES module imports are blocked in a browser's `file://` mode, serve via `python -m http.server 8000` from this folder.

The page is a kinematic artistic/scientific visualization, not a molecular dynamics simulation. Casimir forces, ice phase transitions, Kelvin thermal evolution, actual electrum constitutive laws, and Josephson quantum effects are *not* numerically solved. The witness panel reports model interpretations and sealing occurs in the browser session, not durable provenance.
