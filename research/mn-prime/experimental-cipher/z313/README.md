# Z313 — Triuntrium (Tut): symbolic stellar return map

Classification: Layer 1 speculative cipher. No physical element discovery or actual stellar coordinate is asserted.

Registry:
- Z310 Tun: dormant identity anchor (tardigrade tun analogy).
- Z311 Tuu: rehydration attempt / external input.

- Z313 Tut: identity-continuity and optional repeat-cycle gate.

Star map analogy: observations require identity, position, state, and time. Actual astrophysical catalogs also require coordinate frame and reference epoch. Conceptual diagram points are not sky coordinates.

Invariant: a repeat transition is permitted only after observed successful recovery. Failure does not reset to active.

2. Fixed identity key during one attempted cycle.
3. Allowed transitions dormant->attempt->outcome.
