# Z314 — Triunquadium (Tuq): the observer's sky

Status: symbolic MN PRIME / OCTAVIA candidate, Layer 1 simulation. Not a confirmed chemical element or newly discovered astronomical relationship.

## Three clocks
1. Emission time: source emits light.
2. Propagation interval: light travels between source and observer.
3. Reception time: observer records light.

Simplified stationary model: t_received = t_emitted + d/c.
For distance 100 light-years, propagation time is about 100 years.
