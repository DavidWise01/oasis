# 2. alchemical cipher grammar

This is the working cipher vocabulary used in the overlay:

```text
VESSEL        :: bounded container / body
SOLVE         :: loosen / dissolve / expose
COAGULA       :: bind / fix / solidify
DISTILL       :: separate / carry upward / refine
CIRCULATE     :: repeat through a closed path
SUBLIME       :: volatile -> elevated carrier
FIX           :: volatile -> retained / bound
CONIUNCTIO    :: paired opposites joined
TRANSMUTE     :: state/material identity changed
REAGENT       :: agent that changes another state
TINCTURE      :: small input causing broad transformation
FIRE / HEAT   :: controlled transformation pressure
WATER         :: solvent / carrier / circulation
MERCURY       :: volatile / mobile principle
SULFUR        :: reactive / fixing principle
SUN / GOLD    :: noble / solar metal symbol
MOON / SILVER :: lunar metal symbol
```

Historical note: these ideas do not all belong to one period or one school of alchemy. The corpus uses them as a **cross-period cipher lexicon**, with historical origin kept separate.
