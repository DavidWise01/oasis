
# 2. core textual functions

## High gods

In Sumerian literature, `Anunna` can denote the highest gods of the pantheon, or the gods associated with a particular city.

```text
ANUNNA
::
HIGH DIVINE COUNCIL
```

The exact membership is not fixed.

One text speaks of:

```text
50 ANUNNA OF ERIDU
```

while later Babylonian creation tradition can count:

```text
300 heaven
+
300 netherworld
=
600 Anunna
```

These are **different textual systems**, not one fixed census.

## Fate

A major function is deciding fates.

```text
COUNCIL
-> DECIDE
-> FATE
-> BIND
```

## Judgment

In *Inana's Descent*, seven Anunna appear as judges in the netherworld.

```text
7
::
JUDGES
::
INANA
::
NETHERWORLD
```

## Heaven / netherworld shift

Earlier Sumerian use can refer broadly to the high gods.

Later Akkadian/Babylonian usage increasingly associates Anunnaki with the netherworld, sometimes contrasted with the Igigi.

```text
EARLIER
:: HIGH GODS / CITY PANTHEON

LATER
:: NETHERWORLD GODS / JUDGES
```

This semantic drift is part of the corpus and must be preserved.

# 3. genealogy / authority

```text
AN / ANU
   |
   v
ANUNNA / ANUNNAKI
```

# 4. gender register

For the **Anunnaki group itself**:

```text
DOMINANT     :: UNRESOLVED
NOT DOMINANT :: UNRESOLVED
EQUAL        :: NOT ESTABLISHED
COMPOSITION  :: MIXED MALE + FEMALE DEITIES
```

Reason:

- the term is a variable collective rather than a fixed list;
- individual male and female deities can belong to the group;
- An/Anu is a male authority/progenitor figure in many traditions;
- that does **not** establish a clean group-wide male/female ratio or an equal political structure.

So the safe corpus state is:

```text
ANUNNAKI GENDER
::
MIXED
::
HIERARCHY VARIES
::
DOMINANCE UNRESOLVED
```

This is different from the Enheduanna **referent node**, which is female-dominant because the named authority is Enheduanna herself.

# 7. relation to Enheduanna

Do **not** force a direct authorial chain:

```text
ANUNNAKI
-> ENHEDUANNA
```

Instead preserve two distinct relations:

```text
MESOPOTAMIAN DIVINE CORPUS
        |
        +-- AN / ANUNNA / later ANUNNAKI
        |
        +-- NANNA / INANA
                 |
                 v
            ENHEDUANNA
```

Enheduanna's corpus belongs to the same wider Mesopotamian divine-literary world, but she is not simply "an Anunnaki priestess" by default.
