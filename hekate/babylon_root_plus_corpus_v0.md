Babylon did not invent every upstream component. It inherited and transformed older Mesopotamian cuneiform, counting, accounting, and lexical traditions. This file keeps those ancestry boundaries explicit.

# 1. Strongest Babylonian corpus primitives

## 1.1 RECORD

```text
ROOT+ :: RECORD
clay + stylus -> durable state
```

Cuneiform tablets preserved administrative accounts, contracts, literature, medicine, mathematics, astronomical observations, lexical lists, and royal texts.

**Corpus relation:** provenance / append / durable state.

## 1.2 POSITION

```text
ROOT+ :: 60
position -> value
```

Old Babylonian mathematics used a positional sexagesimal system. The key conceptual move is not merely 'base 60'; it is that a symbol's position contributes to its value.

**Corpus relation:** address / slot / coordinate.

Important boundary:

```text
Babylonian placeholder practice
!=
modern numeric zero
!=
Root0 0
```

Do not back-project the Root0 homeostatic `0` into Babylonian mathematics.

## 1.3 LOOKUP

```text
TABLE :: SQUARES :: CUBES :: RECIPROCALS
```

Babylonian mathematical practice made heavy use of precomputed tables. Multiplication and division could be transformed into table lookups and reciprocal operations.

**Corpus relation:** cached operator / deterministic lookup / compression.

## 1.4 APPROXIMATE

```text
NO FINITE REPRESENTATION
-> approximate
-> mark the limitation
```

Babylonian reciprocal practice includes explicit approximation when a divisor does not terminate cleanly in sexagesimal notation.

**Corpus relation:** unresolved-but-usable rather than silently exact.

## 1.5 OBSERVE -> LOG -> PREDICT

```text
SKY
  |
OBSERVE
  |
LOG
  |
RECURRING PATTERN
  |
PREDICT
```

Late Babylonian astronomy recorded lunar, planetary, and eclipse phenomena and developed numerical schemes for predicting future phenomena. Surviving almanacs include lunar visibility, five visible planets, and eclipse information.

**Corpus relation:** time-series ledger / recurrence / predictive table.

## 1.6 IF -> THEN

```text
IF condition
THEN consequence
```

The Hammurabi jurisprudence collection is organized through conditional case structure: a scenario followed by a judgment or consequence.

**Corpus relation:** rule engine / deterministic branch.

## 1.7 CONTRACT -> WITNESS -> DATE

```text
PARTIES
  +
ASSET / OBLIGATION
  +
WITNESSES
  +
DATE
  ->
BOUND RECORD
```

Babylonian archives preserve leases, land sales, loans, promissory notes, property transfers, and administrative records.

**Corpus relation:** provenance / authority / responsibility / append-only transaction.

## 1.8 SYMPTOM -> DIAGNOSIS -> PROGNOSIS

```text
OBSERVE BODY
  |
SYMPTOMS
  |
CLASSIFY
  |
DIAGNOSIS / PROGNOSIS
```

Babylonian diagnostic handbooks organized signs and outcomes systematically. Their causal framework mixed empirical observation with divination and supernatural explanation, so this is not equivalent to modern biomedical science.

**Corpus relation:** classifier / decision tree / structured observation.

## 1.9 VERSION -> CANON -> COPY

```text
many inherited texts
-> edit / standardize
-> canonical series
-> copy across generations
```

Babylonian scholarship repeatedly standardized inherited material: lexical series, medical handbooks, and literary works.

**Corpus relation:** versioning / freeze / canonical parent / descendants.

## 1.10 SURVEY -> BUILD -> MAINTAIN

```text
LAND / CANAL
-> MEASURE
-> CALCULATE
-> BUILD / MAINTAIN
```

Mathematical texts and administrative practice connect calculation with canal excavation, land measurement, irrigation, labor, and allocation.

**Corpus relation:** geometry bound to operations.

# 2. What Babylon was especially strong at

## A. Mathematics

```text
SEXAGESIMAL POSITION
+
TABLE-DRIVEN COMPUTATION
+
RECIPROCALS
+
QUADRATIC / CUBIC PROCEDURES
+
GEOMETRY
+
APPROXIMATION
```

Examples preserved in the corpus include:

- square and cube tables;
- reciprocal tables;
- YBC 7289 with a very accurate approximation to `sqrt(2)`;
- right-triangle problem traditions including Plimpton 322;
- numerical procedures equivalent, in modern notation, to solving classes of quadratic and cubic problems;
- canal and land-survey calculations.

Plimpton 322's exact original purpose remains debated; do not freeze it as 'the first trigonometry table' or as proof of a modern theorem-concept.

## B. Astronomy

```text
LONG OBSERVATION
-> PERIODICITY
-> TABLE
-> EPHEMERIS / ALMANAC
```

Babylonian astronomers were particularly strong at long-run numerical observation and prediction rather than geometric cosmological modeling. Surviving Late Babylonian material includes eclipse tables, lunar ephemerides, Venus and planetary data, and almanacs.

## C. Scribal education / knowledge organization

```text
SIGN LIST
WORD LIST
TEACHER MODEL
STUDENT COPY
CURRICULUM
REFERENCE CORPUS
```

Old Babylonian lexical texts became a systematic curriculum for learning cuneiform and Sumerian. In later periods many of those lists also functioned as scholarly reference works.

## D. Law and administration

```text
CASE
-> RULE
-> JUDGMENT

TRANSACTION
-> CONTRACT
-> WITNESS
-> ARCHIVE
```

The legal and administrative corpus is unusually rich: family law, property, trade, labor, leases, loans, sales, taxes, and state/temple administration.

## E. Medicine / diagnosis

```text
BODY
-> OBSERVE
-> CLASSIFY
-> EXPECT OUTCOME
```

Babylonian medicine preserved recipes, materia medica, therapeutic instructions, and diagnostic/prognostic series. The observational structure is historically important even though the explanatory model often includes gods, demons, omens, or ritual.

## F. Literature / textual preservation

```text
OLD STORY
-> EDIT
-> STANDARD FORM
-> COPY
-> SURVIVE
```

The Babylonian scholarly corpus preserved and reshaped inherited Mesopotamian literature, most famously the Standard Babylonian Epic of Gilgamesh.

## G. Accounting / commerce

```text
QUANTITY
+
PERSON
+
DATE
+
OBLIGATION
-> LEDGER
```

Thousands of cuneiform records preserve grain, land, leases, debts, silver obligations, wages, deliveries, and other transactions.

## H. Irrigation / surveying / practical geometry

```text
WATER
-> CANAL
-> FIELD
-> MEASURE
-> ALLOCATE
```

Lower Mesopotamian agriculture depended on managed canal systems. Texts attest irrigation terminology, canal maintenance, land surveys, and mathematical calculations associated with excavation and fields.

# 3. Recorded people — evidence-weighted

## Hammurabi — king of Babylon, 18th century BCE

```text
HAMMURABI
::
JURISPRUDENCE / STATE ADMINISTRATION
```

Securely historical. The famous stela preserves roughly 282 judgments covering family, property, trade, labor, injury, and other disputes. It is better described as a large jurisprudential collection than a modern exhaustive legal code.

**Corpus relation:** `IF -> THEN -> BIND`.

## Sîn-lēqi-unninni — scholar traditionally linked to Standard Babylonian Gilgamesh

```text
SIN-LEQI-UNNINNI
::
EDITOR / STANDARDIZER
```

Babylonian tradition associates him with the Standard Babylonian form of the Epic of Gilgamesh, probably in the late second millennium BCE. Modern scholarship generally treats him as a traditional editor/redactor figure rather than safely calling him the sole modern-style author.

**Corpus relation:** `VERSION -> CANON -> COPY`.

## Esagil-kīn-apli — scholar, 11th century BCE

```text
ESAGIL-KIN-APLI
::
DIAGNOSTIC HANDBOOK STANDARDIZER
```

Associated with the systematic redaction of the forty-tablet diagnostic series during the reign of Adad-apla-iddina. His organization helped produce a durable reference tradition used for centuries.

**Corpus relation:** `OBSERVE -> CLASSIFY -> CANON`.

## Nebuchadnezzar II — king of Babylon, 605–562 BCE

```text
NEBUCHADNEZZAR II
::
URBAN / IMPERIAL BUILD
```

Securely historical. Important here less as a scientific discoverer than as a state builder whose reign generated major architecture, inscriptions, administration, and preservation activity.

**Corpus relation:** `STATE -> BUILD -> RECORD`.

## Nabonidus — last Neo-Babylonian king, 556–539 BCE

```text
NABONIDUS
::
ARCHIVE / RESTORATION ERA
```

Securely historical. Hundreds of legal and administrative tablets survive from his reign. He is useful to this corpus primarily as a dated archival anchor, not as a single physics discoverer.

**Corpus relation:** `DATE -> TRANSACTION -> ARCHIVE`.

## Nabû-rimannu / Naburianos — astronomer

```text
NABU-RIMANNU
::
ASTRONOMICAL COMPUTATION
```

Named in ancient traditions and associated with Babylonian computational astronomy. Specific claims that he invented a particular astronomical System A are uncertain.

**Corpus relation:** `TABLE -> EPHEMERIS`.

## Kidinnu / Kidenas — astronomer

```text
KIDINNU
::
LUNAR / ASTRONOMICAL TRADITION
```

Named in ancient sources as a Chaldean/Babylonian astronomer. Later scholarship has connected him with System B and lunar parameters, but authorship of the entire system is not secure.

**Corpus relation:** `PERIOD -> PREDICT`; **attribution STOP** beyond that.

## Sudines — Chaldean astronomer

```text
SUDINES
::
ASTRONOMICAL SCHOOL
```

Named by Strabo among notable Chaldean astronomers. Detailed surviving biographical and technical information is sparse.

**Corpus relation:** named node; technical payload largely unresolved.

## Berossus — Babylonian priest/chronicler, late 4th–early 3rd century BCE

```text
BEROSSUS
::
BABYLONIAN CORPUS -> GREEK-LANGUAGE TRANSMISSION
```

A priest of Bel/Marduk at Babylon who wrote a history of Babylonia in Greek using native traditions and documents. His original work is lost and survives only through later quotations/fragments.

**Corpus relation:** `NATIVE ARCHIVE -> TRANSLATE -> EXTERNAL CORPUS`.

## Seleucus of Seleucia — Hellenistic Chaldean astronomer

```text
SELEUCUS
::
CHALDEAN / HELLENISTIC ASTRONOMY
```

Strabo calls Seleucus of Seleucia a Chaldean astronomer. He belongs to the broader late Mesopotamian/Babylonian astronomical tradition, but should not be silently treated as a resident of Babylon city.

**Corpus relation:** downstream astronomical branch.

# 4. Upstream people who are NOT Babylonian but belong to ancestry

## Enheduanna

```text
UPSTREAM AKKADIAN / SUMERIAN-MESOPOTAMIAN CORPUS
NOT BABYLONIAN
```

Yale identifies Enheduanna as the earliest author whose work is known by name in its Mesopotamian collection tradition. She predates Babylonian civilization and therefore sits above Babylon in ancestry, not inside the Babylon layer.
