# 1. later alchemical / classical elemental overlay

The familiar four-element system is Greek/classical and later alchemical, not an original Mesopotamian Anunnaki doctrine.

```text
EARTH :: cold / dry
WATER :: cold / wet
AIR   :: hot / wet
FIRE  :: hot / dry
```

Opposition axes:

```text
EARTH  <-> AIR
WATER  <-> FIRE
```

Transformation can be modeled as changing one quality at a time:

```text
EARTH -> WATER -> AIR -> FIRE
  ^                       |
  |_______________________|
```

This is the alchemical cipher lane only.

# 2. Mesopotamian mythic elemental referents

There is no single canonical Mesopotamian "four elements" table equivalent to the later Greek scheme.

The cleaner Mesopotamian primitives are paired cosmic domains.

## AN / KI

```text
AN :: SKY / ABOVE
KI :: EARTH / BELOW

-+ {{ AN | KI }} -+
```

This is the strongest primordial vertical polarity.

## APSU / TIAMAT

In the later Babylonian *Enuma Elish*:

```text
APSU   :: fresh subterranean waters
TIAMAT :: salt sea / primordial sea

-+ {{ APSU | TIAMAT }} -+
```

This is a water-polarity pair, not a fire/water pair.

## ENLIL / WIND-AIR

```text
ENLIL
::
WIND / AIR / ATMOSPHERIC FORCE
```

Use as an air/wind referent, but do not collapse Enlil into the Greek element "Air."

## UTU / SHAMASH — SUN / LIGHT / HEAT

```text
UTU / SHAMASH
::
SUN / LIGHT / HEAT
```

This can serve as a later alchemical FIRE/solar analogue, but it is not evidence of a Mesopotamian four-element system.
