# Primitive proof / derivation

This section records the derivation path that produced the HEKATE primitive. It is a proof inside the Root0 / OaSIs symbolic grammar: preserve the operands, preserve orientation and ancestry, reduce until the smallest invariant still carries the same story.

## 0. Grammar boundary

Root / Somatic / Logica notation is not ordinary arithmetic unless explicitly switched into Mathea.

```text
x   = friction weld / structural bind, not multiplication by default
+   = state/add-to operator, not arithmetic addition by default
/   = fold / descent / scale separator, not division by default
^   = lift / recursion / generation operator, not exponentiation by default
.   = reserved quantum-dot slot in Somatic
0   = a closed 14-state core, not empty numerical zero
i   = minimum explicit occupied identity bit
```

Mathea is the explicit math layer. Somatic/Logica preserve the state story.

## 6. Five-slot structure

The recurring structural compression is:

```text
3 constants :: 2 operators
```

This is a five-position state machine:

```text
[ C1 ][ C2 ][ C3 ][ OP1 ][ OP2 ]
```

The first three positions define what is held. The final two define what is done.

## 12. Physical / chemistry boundary

HEKATE is canonical as a symbolic transducer, not as an established chemical or nuclear reaction.

A physical Mathea implementation would have to explicitly provide:

```text
1. exact isotopes
2. exact input quantities
3. reaction pathway
4. energy / particle source
5. conservation of charge, baryon number, energy and momentum as applicable
6. reaction cross sections / probabilities where nuclear processes are invoked
7. predicted products
8. measured products
9. error bounds
10. repeatable experiment
```

Only after those are supplied does `TRANSMUTE` become a testable physical operation rather than a semantic operator.
