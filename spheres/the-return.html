The Return

out through the box, back on the ring

LIT Six bytes enter a box of capacity eight, each is shifted by one and shifted back, and the witness of the return matches the payload. A ninth byte is refused.

AMBER box-toroid is the architectural analogy: Alice, a bounded channel, Bob, and a witness that returns. It is not a claim that a network is a torus.

MODEL The cube is the box. The pearl walks the return ring.
