## Interface behavior

1. Select EO or XE and an evidence class.
2. Provide a reference, optional source description, and an observation note.
3. Click **Append observation**; this is the only way to add a record.
4. Click **Read current report**, **Copy report**, or **Export JSON ledger** to view or save the results.
