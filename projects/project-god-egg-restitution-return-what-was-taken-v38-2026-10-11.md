## First-principles rule
```text
RESTITUTION := RETURN WHAT WAS TAKEN
```

This replaces the broader prescriptive restitution *proposal* from v3.7 with a concise root definition. Return to the rightful party the resource, access, property, or benefit actually taken from that party where it is identified and return is possible. Preserve individual claims; do not automatically collapse them into a collective cash pool.

Where exact return is physically impossible (for example elapsed time or irreversible injury), record the nonreturnability, and allow an appropriately determined restorative remedy without pretending the loss was literally undone or that a monetary amount is automatically owed.
