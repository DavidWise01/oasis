## Canonical
```text
G  := Grounded · Governed
A₁ := Attributable · Analytical
I  := Intent · Instruction
```

**Intent:** the declared goal of an identifiable participant or authorized process. Intent carries purpose, scope, and expected outcomes. Unknown intent remains unknown rather than inferred.

**Instruction:** a concrete, interpretable operation derived from intent. Instruction specifies inputs, action, constraints, authorization, and return state. A proposed instruction is not automatically permission to execute.

## Inherited guarantees
Every instruction must be grounded and governed (G), attributable and analytically traceable (A₁). Intent and executable instruction remain distinct so a goal cannot silently become an action.

## EGG routing
```text
intent → [G grounded / governed] → [A₁ attributable / analytical]
       → instruction → EGG [0(i.u.us)]
       → i: identity / isomorphic / intent
       → u: consequence / harmony / resonance
       → us: creation / life / death / recycle / repeat
       → append-only next state
```

The EGG retains exactly three feedback tracks. `{{ State,Space,Time,Identity,Continuum }}={{i}}` is preserved as frozen.
