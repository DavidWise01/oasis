# Feng Shui / Spatial Lens

This is the first public OaSIs domain lens.

The engine uses **9 families × 9 primitives = 81 spatial primitives**:

1. Site
2. Boundary
3. Entrance
4. Path / flow
5. Center
6. Orientation
7. Balance
8. Material & light
9. Human fit

## Evidence boundary

Feng shui is treated as a historical and cultural spatial-design tradition. OaSIs may use its vocabulary as a memory and design lens. Practical recommendations should be checked against direct observation, accessibility, circulation, daylight, environmental conditions, task fit, and occupant preference.

Metaphysical claims such as measurable qi are not encoded as established physical facts.

## Surface rule

The engine may retain all 81 primitives internally. A human-facing attachment should expose only the smallest number of choices required for the current decision.
