# OaSIs Tattoo Skill Atlas v00
Five workflow skills. Each skill has **9 families × 9 categories = 81 hidden engine categories**. Total: **405**.
The atlas is intentionally implicit: it is for engine reasoning/scoring, not for presenting 405 controls to a person.
